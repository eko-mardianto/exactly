## Architecture Principles

Established the foundational principles that guide how Exactly should be designed, structured, developed, and evolved.

The principles establish direction for:

- Modularity
- Separation of Concerns
- Simplicity
- Maintainability
- Scalability
- Security
- Testability
- Documentation

The Architecture Principles remain technology-agnostic and define architectural direction without prematurely prescribing implementation technologies or frameworks.

---

## Initial Repository Structure

Established the foundational repository-level structure of Exactly.

The structure defines clear boundaries between:

- Documentation
- Application code
- Public assets
- Project-level files

The repository structure intentionally does not define internal application architecture.

Detailed application structure remains part of Phase 3 — System Architecture.
