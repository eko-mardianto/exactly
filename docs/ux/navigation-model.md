# Navigation Model

## Purpose

Navigation Model defines how users move between the major areas of Exactly while pursuing their goals.

Rather than defining specific interface components or visual layouts, this document establishes the structural model that connects information, user flows, and product areas.

It provides the foundation for designing navigation that helps users find relevant information, maintain context, and progress through the product without unnecessary complexity.

## Navigation Principles

Navigation Principles define the enduring principles that guide how users move through Exactly.

These principles ensure that navigation supports understanding rather than becoming an additional source of complexity.

---

### Clarity Before Completeness

Navigation should make important destinations easy to understand before attempting to expose every possible destination.

Not every available function needs to be visible at all times.

---

### Context Before Choice

Navigation should provide relevant options based on the user's current context.

Users should not be required to understand the entire product structure before completing a meaningful task.

---

### Stable Structure

Core navigation should remain predictable as the product evolves.

Changes to individual features should not unnecessarily disrupt the user's understanding of where information belongs.

---

### Minimize Navigation Depth

Users should reach meaningful information without unnecessary layers of navigation.

Additional levels should only exist when they provide meaningful organizational value.

---

### Preserve Context

Navigation should help users understand where they are and maintain the context of the information they are exploring.

Moving between related information should not unnecessarily break the user's understanding.

---

### Support Exploration

Navigation should make it easy to discover related information without forcing users away from their current context.

Exploration should be possible without making the user's original goal difficult to recover.

---

Navigation should reduce the effort required to find and understand information without reducing the depth of the experience.
