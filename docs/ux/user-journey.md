# User Journey

## Purpose

User Journey defines how users progress from uncertainty to understanding while using Exactly.

Rather than documenting interface interactions or navigation paths, this document describes the transformation users experience as they explore information, evaluate evidence, build understanding, and make informed decisions.

It provides the experiential foundation for designing workflows, navigation, and interactions throughout the product.

---

## Journey Principles

Journey Principles define the enduring principles that guide how users should experience Exactly.

These principles ensure that every stage of the journey supports learning, understanding, and confident decision-making.

---

### Curiosity Before Confidence

The journey should encourage exploration before encouraging conclusions.

Users should feel comfortable asking questions and discovering information before reaching decisions.

---

### Learn Before Decide

Every stage should increase understanding before asking users to make decisions.

Understanding should always precede confidence.

---

### Reflection Before Action

Users should have opportunities to review evidence, reasoning, and context before acting.

The product should encourage thoughtful decision-making rather than immediate reactions.

---

### Progressive Understanding

Information should become increasingly meaningful as users move through the journey.

Each stage should build naturally upon previous understanding.

---

### Reduce Cognitive Friction

The journey should minimize unnecessary effort while preserving meaningful thinking.

Complexity should be reduced without removing important reasoning.

---

Every stage of the journey should strengthen understanding rather than simply moving users toward completion.

---

## Journey Stages

The Exactly experience is organized around six stages of understanding.

### Question

Users begin with uncertainty, curiosity, or a decision that requires better understanding.

---

### Explore

Users discover relevant information, evidence, and perspectives related to their question.

---

### Understand

Users build a coherent understanding by connecting evidence, explanations, and reasoning.

---

### Evaluate

Users assess the strength, relevance, and reliability of available information.

---

### Decide

Users apply their own judgment to make informed decisions.

Exactly supports this process without replacing personal responsibility.

---

### Reflect

Users review outcomes, revisit previous reasoning, and continue learning from past decisions.

Reflection reinforces future understanding rather than ending the journey.

---

## Journey Goals

The journey should help users:

- Understand before deciding.
- Evaluate evidence objectively.
- Develop confidence through reasoning.
- Learn continuously from previous decisions.
- Strengthen independent judgment.

---

## Journey Challenges

The journey should minimize experiences that reduce understanding, including:

- Information overload.
- Hidden reasoning.
- Unsupported conclusions.
- Fragmented information.
- Premature recommendations.
- Decision pressure without sufficient context.

---

## User Journey Statement

User Journey defines the intended evolution of understanding throughout Exactly.

It serves as a shared reference for product, UX, design, and engineering teams when creating experiences that support thoughtful decision-making.

As the product evolves, new journeys and scenarios may be introduced.

The underlying journey principles should remain stable to ensure that every experience continues to strengthen understanding before supporting decisions.
