# Project Goal

Build an AI platform that helps people understand complex information before making decisions.

Exactly is designed to strengthen human reasoning rather than replace it.

The project prioritizes:

- Understanding before deciding
- Evidence before assumptions
- Simplicity before complexity
- Learning before automation

---

# Project Vision

# Guiding Principles

Every phase of development follows these principles.

1. Documentation before implementation.
2. Understand before building.
3. Solve real problems before adding features.
4. Prefer clarity over cleverness.
5. Build for long-term maintainability.
6. Small improvements accumulate into great products.
7. Every important decision deserves documentation.

---

# Definition of Success

Exactly is successful when users say:

> "Now it makes sense."

—not because the product gave them an answer,

but because it helped them understand.

# Maintenance Rule

ROADMAP.md defines the long-term direction of the project.

It should only be updated when:

- a new project phase is introduced,
- the project's long-term strategy changes,
- or the project's vision fundamentally evolves.

Routine sprint planning belongs in Sprint documents, not in this roadmap.
