# ADR-001

## Title

Documentation First Development

---

## Status

Accepted

---

## Date

2026-08-05

---

## Context

Exactly is intended to become a long-term product with evolving features, architecture, branding, and intelligent capabilities.

Without consistent documentation, project knowledge can easily become fragmented, leading to repeated discussions, forgotten decisions, inconsistent implementations, and unnecessary technical debt.

To ensure long-term maintainability, the project requires a documentation strategy that evolves together with the product and its codebase.

---

## Decision

Exactly adopts a **Documentation First** development workflow.

Every significant product, engineering, architectural, and branding decision should be documented before implementation begins.

Documentation is considered an integral part of the product rather than an afterthought.

The project's core documentation includes:

- Roadmap
- Sprint Documentation
- Brand Documentation
- Product Documentation
- Changelog
- Project History
- Architecture Decision Records (ADR)

Implementation follows only after the relevant documentation has been reviewed and agreed upon.

---

## Consequences

### Positive

- Clear long-term project direction
- Better decision traceability
- Consistent product evolution
- Easier onboarding for future contributors
- Reduced repeated discussions
- Lower long-term maintenance cost
- More predictable development workflow

### Negative

- Slightly slower planning at the beginning of each sprint
- Requires discipline to keep documentation synchronized with implementation
- Documentation becomes part of every development task

## Notes

Documentation First is a permanent development principle of Exactly.

Documentation is not merely a record of implementation; it is an integral part of product development.

Whenever implementation and documentation diverge, the documentation should be reviewed and updated to preserve a single source of truth.

The objective is not to produce more documentation, but to ensure that every important decision is documented, understood, and traceable before implementation begins.
